# Public Repository Adapter

This repository is a public, sanitized reference implementation of the Personal World Model Harness.

When reviewing or editing this repository:

1. Treat `docs/` as design documentation, not private user context.
2. Treat `template/` as a generic runnable example, not a real person's vault.
3. Preserve the distinction between `validated-in-use`, `supported-by-failure`, `testing`, and `candidate` claims.
4. Do not add real personal data, private conversation history, credentials, local absolute paths, or third-party full-text material.
5. Prefer the smallest change that improves reproducibility or explanatory value.
6. Do not initialize Git, create a remote repository, or publish content without explicit owner approval.

For a runtime demonstration, follow `template/AGENTS.md` and load only the minimum files required by the demo task.
