# 公开发布检查

## 当前更新：2026-10-27

用户已于2026-10-27审阅本地预览并明确确认推送。正式发布只来自独立公开仓库，不从私有 Vault 全量同步。

### 每次发布实际检查

- 检查改动清单、远端与工作区状态；保留已有独立修改。
- 对照当前设计，而非仅在旧首页后追加功能；中英文定位、模板和文档不相互矛盾。
- 区分本仓库交付、私有实现经验和候选能力；不把文档写成已打包的软件。
- 检查全部相对链接、模板入口、状态引用和代码块；真实教学效果另作行为验证。
- 检查私人资料、凭据、设备路径、账号连接标识、原始聊天与未授权第三方全文；关键词扫描不能代替语义审阅。
- 历史例子注明范围，不将旧状态改写成当前，也不因有风险提示就忽略内容本身。
- 大范围改版先本地预览、用户确认后再提交推送。确认的是此次版本；后续实质变化重新呈现。
- 推送后核对本地与远端提交一致，才报告已发布。

自动检查只辅助上述判断。MIT 许可不赋予发布第三方材料的权限。
