# Publication Checklist

首次公开前逐项检查：

## Privacy

- [x] 不含真实 USER / STATE；
- [x] 不含姓名、对象、家人、雇主、群聊或现实组织细节；
- [x] 不含联系方式、账号、Token、私钥或环境变量；
- [x] 不含本地绝对路径；
- [x] 不含 Obsidian `workspace.json`；
- [x] Git 历史从脱敏版本开始。

## Copyright

- [x] 不含无再分发许可的第三方 PDF；
- [x] 不复制付费文章、课程或完整对话；
- [x] 示例引用有来源和合理长度；
- [x] LICENSE 已由项目 Owner 确认并采用全仓统一 MIT License。

## Claims

- [x] `testing` 没有被写成最佳实践；
- [x] 真实验证与设计推断明确区分；
- [x] Demo 标明经过脱敏或合成；
- [x] 公开 Case Study 如重构用户表达，已明确标注为非逐字引语；私有 Source Note 继续保留原文；
- [x] 不宣称系统能够自动判断真理；
- [x] 不把 Markdown 模板包装成完全自治 Agent。

## Repository

- [x] README 能解释问题、架构、运行方式和边界；
- [x] Template 可以独立复制；
- [x] 至少一个 Demo 可从输入走到 STATE 更新；
- [x] `.gitignore` 覆盖设备状态与私有导出；
- [x] 先创建 Private Repository 并复核；
- [x] Owner 最终确认后再转 Public。
