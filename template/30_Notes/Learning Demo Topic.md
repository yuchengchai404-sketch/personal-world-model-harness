## Fictional material

A learner revisits the phrase “feedback changes goals.” It sounds familiar but no longer explains anything.

The example compares imagining a reading desk with trying a cardboard mock-up. Before trying it, the learner asks for more surface area. After placing it in the room, the learner notices light and reach matter more than size. Feedback changes not only the object but what the learner wants from it.

This invented example illustrates a distinction; it is not empirical evidence that prototypes always improve goals. The scope condition is that the trial reveals information relevant to the choice.
