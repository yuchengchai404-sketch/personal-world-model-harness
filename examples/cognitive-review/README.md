# 回顾不是把摘要放大
合成示例；不引用私有经历，也不代表新一轮用户实测。

## 后台摘要

> 反馈可改变目标，而不只是修正执行。

系统可以用它检索相关判断，但忘掉背景的人可能读完仍不知道是什么意思。

## 面向人的回顾

### 为什么试做一下，反而让我改了目标？

你以为自己需要一张更大的桌子。把纸板轮廓放进房间，才发现它挡光，而且远处够不到。

试做的价值不只是告诉你“这个尺寸不行”，还让你发现：原来想要的不只是更多面积，而是一个用起来舒服的空间。

所以，反馈有时改变的是作品，有时连“想做成什么”也一起改变。前提是试作带来了与选择相关的新信息，而不是把每次摇摆都解释成成长。

**表达草稿，尚无用户确认：**“有些想法，要先做出一点样子，我才知道自己真正想要什么。”

## 用途和接续

地图节点用问题帮助辨认；正文恢复解释；表达帮助讲述；来源保存判断与依据。关系图可以把“原目标—试作—新信息—目标调整”画出来，不必增加同义正文。

这个例子不证明原理的普遍有效，只展示内容编辑的区别。实际可导航版本见[模板 Review](../../template/30_Notes/Demo%20Review.md)。真实成品还要检查检索、返回、复制、来源及阅读效果。
