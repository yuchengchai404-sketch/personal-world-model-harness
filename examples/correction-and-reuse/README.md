# 把更正送到下一次会用的位置
合成例子，展示修复方法，不是私有事件逐字记录。

## 问题

一个 Note 的主句仍写“扩大规模就能降低成本”。后面的修订说明已经改成“固定成本能分摊，但协调成本也可能上升”。恢复点和表达索引却仍指向旧句。

如果只检查“文件有没有修订说明”，会误判已修复。

## 有限改法

- 保留原说法与当时的状态作为历史，不改写成“从来就这样说”。
- 当前主句明确规模效应的条件，直接关联依据。
- 旧表达旁标明已被哪一版取代；新表达若要正式采用，呈现具体稿并获得确认。
- 更新实际使用的 Resume 和引用入口，不遍历无关资产制造新工作。

## 验收

从恢复点进入、从表达索引进入、只读取主句：三条路径都不应把旧说法当现行结论。原话、历史及批准仍可回查。未决证据继续未决。

入口修复完成可以结案；它不证明成本模型在现实中已经有效。参见[Operations](../../template/00_System/Runtime%20Operations.md)。
